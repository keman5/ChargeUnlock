PlugLit is a charging Picture in Picture utility, not a screen-unlock tool. It does not change system Auto-Lock settings or bypass the passcode. No login or paid features are required.

Testing steps:
1. Use a physical iPhone running iOS 15 or later and connect power. Simulator battery state may be unknown and cannot demonstrate the core feature.
2. Tap Start Keep Awake. The bundled silent charging animation displays the system battery reading in PiP. Swipe Home manually to switch apps.
3. Disconnect power or open the app and tap Stop Keep Awake. Playback and PiP stop; the system's original Auto-Lock settings apply.
4. On iOS 17 or later, Guide explains optional user-created Shortcuts charger automations. On iOS 15/16 use the main screen to start manually; unplugging power still stops playback. The application cannot install personal automations or unlock the phone.
5. About → Feedback & diagnostics: inspect/export the diagnostic report. Diagnostic upload is off by default. A feedback submission needs explicit consent and contains only the optional report, user description and optional contact email.

Background mode audio is used for AVKit Picture in Picture playback of the bundled charging visualization. The intent is to keep the display awake while charging; we disclose this purpose explicitly and request review of this use. We do not claim this guarantees compliance with guideline 2.5.4. No private API or executable-code download/update mechanism is included.

App UI, guide and in-app privacy/terms support English, Simplified Chinese, Spanish, French, German, Japanese and Korean, following system language preferences with English fallback.
