# 电亮 PlugLit

电亮 PlugLit 是 iPhone 充电亮屏工具：通过画中画显示充电动画和系统电量，插电时保持亮屏，拔电或停止后沿用原有自动锁定设置。仅保留独立 iOS 应用；旧 Mac 助手、Runner 工程及其构建、安装和测试入口均已移除。

## 电亮 PlugLit · iPhone 独立版

原 ChargeUnlock iOS 版现改名为“电亮”，英文名 PlugLit。保留原 bundle ID、AppIntent 类型及 `chargeunlock://start` / `stop` 地址以兼容已有安装；另支持 `pluglit://start` / `stop`。

支持 iOS 17 及以上，通过系统画中画播放本地无声充电动画。无需 Mac 持续连接。首次普通打开自动展示图文步骤指南；首页“自动化设置与使用指南”可反复查看。停止状态显示电量、连接状态和系统锁屏说明，不留空白卡片。

```sh
./build.sh ios-install DEVICE_UDID TEAM_ID
```

通过根脚本执行测试、生成并校验 6 秒 / 360 帧 / 60 fps 视频、构建签名、安装并启动；仅构建使用 `ios` 模式。签名团队在忽略的 `iOS/Signing.local.xcconfig` 中，缓存位于 `~/Library/Caches/ChargeUnlock/iOS/`。

### 内置快捷动作与首次配置

安装后由 AppShortcutsProvider 向系统提供两个动作，无需下载 `.shortcut` 文件：

- **开启充电亮屏**：打开电亮并尝试启动画中画。
- **停止充电亮屏**：关闭画中画，恢复原来的自动锁屏行为。

首页的单个按钮随状态切换开启 / 停止；快捷动作仍保留两个，以兼容插电和拔电自动化。指南使用图标步骤和卡片，详细说明默认折叠。

指南底部使用 Apple 的 ShortcutsUIButton 打开本 App 在“快捷指令”中的页面。动作自动提供，不等于充电器触发规则已配置；App 无法自动安装、读取或删除个人自动化。

1. 打开系统“快捷指令”→“自动化”→“+”→“充电器”。选择“已连接”和“立即运行”，添加电亮的“开启充电亮屏”，保存。
2. 再创建一条“充电器”→“已断开”→“立即运行”，添加“停止充电亮屏”，保存。
3. 若编辑器让你先创建空白自动化，选择“添加操作”后搜索上述动作。若系统版本在快捷指令内提供自动化触发器，则添加对应的充电器触发器并确认启用。
4. 解锁后拔插电源，确认插电出现画中画、拔电关闭，随后按原来的自动锁定时间熄屏。停止不是立即锁屏；“永不”设置不会被改变。

锁屏插电可能需要先解锁；不会绕过密码。原来的自动化若仍引用旧名称，可在系统编辑器中核对或重新选择新名称的动作。

### 画中画与充电动画

- 闪电轮廓内的橙色自下而上扫描填充，使用 960×540 / 60 fps 视频源，Core Image 视频合成叠加当前系统电量与“正在充电 / 电量已满”状态。读数变化通过电池通知、打开应用即时刷新，以及前台和播放期间每秒补查更新，未知读数不伪造百分比。
- **60 fps 不等于强制 60 Hz**。实际播放刷新率由 iOS、屏幕、低电量模式与温度决定；高帧率播放有耗电和发热成本。
- iOS 没有公开接口控制 PiP 窗口位置、尺寸或自动收起。可手动双指捏合缩小，拖到角落，或向左右边缘滑动收起；电亮沿用 iOS 管理和记住的窗口尺寸，跨会话记忆需在目标设备验证。隐藏后是否继续防锁屏仍须真机确认；若会熄屏，应保留屏幕内最小窗口。
- 暂停、关闭窗口或其他媒体打断可能结束亮屏。拔电后关闭画中画，沿用系统锁屏设置。
- 启动成功后自动返回桌面的既有行为使用私有退后台接口，仅用于本机开发安装，不适用于 App Store；不支持时需手动上滑返回桌面。

### 停用、删除与卸载

- 当前会话：点“停止充电亮屏”，下次插电仍可能自动开启。
- 暂停自动化：系统“快捷指令”→“自动化”→分别关闭两条规则，或选择“不运行”。
- 删除配置：在自动化列表左滑删除对应规则；使用内嵌触发器的版本可在快捷指令编辑器中移除触发器。用户另存的快捷指令副本可以长按删除。
- 卸载 App：先停止亮屏、停用或删除两条规则，再长按桌面“电亮”→“移除 App”→“删除 App”。内置动作随 App 移除；遗留的个人自动化需手动清理，以免失败提醒。

### 验证

`./build.sh test` 覆盖断电、异步关闭状态、电量边界与实际 Core Image 电量叠加。视频生成器会验证帧率、时长和 360 个编码帧。

`./build.sh simulator` 构建模拟器版本供界面检查。真机使用 `ios-install` 模式，只安装电亮本体，不安装任何测试助手。旧 `runner`、`run`、`ios-test`、`mac`、`install` 参数已移除。防锁屏时长和电量变化在真机上人工验收，避免测试工具干扰。
